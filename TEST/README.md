# ASD Emotional Regulation App – Therapist Web Interface



This repository is intended to contain the therapist-facing web interface
for the ASD Emotional Support Application (ASD Project).

The therapist interface is designed to support clinicians in reviewing
children’s emotional logs, identifying emotional patterns, and providing
professional feedback outside therapy sessions.

--------------------------------------------------
Project Context
--------------------------------------------------
The ASD Emotional Support Application serves three user roles:
- Child (high-functioning autistic child, ages 10+)
- Parent
- Therapist

This repository focuses ONLY on the therapist web interface.
The child and parent experience is implemented as a separate Android
mobile application.

--------------------------------------------------
Current Status
--------------------------------------------------
This repository currently contains early scaffolding and placeholders.
The therapist web interface is in the planning and initial setup phase.

Functional implementation will be added in future iterations, in
accordance with the project requirements.

--------------------------------------------------
Planned Therapist Capabilities
--------------------------------------------------
- View emotional logs of assigned children
- Analyze emotional trends and intensity over time
- Identify high-intensity or “unsure” emotional entries
- Attach professional feedback to emotional logs
- Export summaries for clinical or parent meetings
